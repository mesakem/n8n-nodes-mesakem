# Changelog

## 0.1.0

- Mesakem Trigger: instant webhooks for the 24 Mesakem event types, automatic or manual registration, Standard Webhooks signature check, details fetched by ID (at most two requests per event).
- Mesakem node: meetings (get, get many, summary, transcript, upcoming), tasks (get, get many, create, update, delete), notetaker (send, schedule, cancel), documents (get), account (get).
